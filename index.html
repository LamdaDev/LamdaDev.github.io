TransitOps Montreal

Turning transit telemetry into a clearer picture of route health.

Transit operators need a clear view of service issues. I’m building a dashboard to identify active vehicles, stale updates, route gaps, and bus bunching risk from public GTFS data and live or simulated vehicle snapshots.

  • Go
  • React
  • TypeScript
  • PostgreSQL
  • GTFS
Inside the build +
  • Building the full-stack dashboard with Go, React, TypeScript, and PostgreSQL to analyze STM bus route health.
  • Implementing ingestion and metrics logic for vehicle activity, update freshness, route gaps, and bunching risk.
  • Designing an LLM operations analyst that recommends service actions from route telemetry through an agentic loop. This feature is still in the design stage.
